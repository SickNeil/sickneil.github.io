My Assistant

My Assistant 是 SickNeil 個人自用的待辦管理工具，在自己的電腦上執行，用來讀取與管理自己 Google 帳號中的 Google Tasks（待辦事項）。

My Assistant is a personal tool used only by its developer (SickNeil). It runs locally and reads and manages the developer's own Google Tasks.

功能 / Features

  • 列出待辦清單與待辦事項 / List task lists and tasks
  • 新增、完成、刪除待辦事項 / Create, complete and delete tasks
