隱私權政策 / Privacy Policy

最後更新 / Last updated: 2026-10-20

存取的資料 / Data accessed

My Assistant 透過 Google Tasks API（範圍 https://www.googleapis.com/auth/tasks）存取使用者本人的待辦清單與待辦事項，僅用於顯示、新增、完成與刪除待辦。

My Assistant accesses the user's own task lists and tasks through the Google Tasks API (scope https://www.googleapis.com/auth/tasks), solely to display, create, complete and delete tasks.

資料的儲存與分享 / Storage and sharing

  • 授權 token 只儲存在使用者本人的電腦上，不會上傳到任何伺服器。
    Authorization tokens are stored only on the user's own computer and are never uploaded to any server.
  • 待辦資料不會被儲存、出售或分享給任何第三方。
    Task data is not stored, sold or shared with any third party.
  • 本工具僅供開發者本人使用，不蒐集其他使用者的資料。
    The tool is used only by its developer and collects no data from other users.

Google API 使用規範 / Google API Services User Data Policy

My Assistant 對 Google API 所取得資料的使用，遵守 Google API Services User Data Policy，包括 Limited Use 規範。

My Assistant's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

撤銷授權 / Revoking access

可隨時在 Google 帳戶的第三方存取權設定撤銷授權。
Access can be revoked at any time from Google Account third-party access settings.
